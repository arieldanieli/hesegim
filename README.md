# הישגים בגיטהאב- למה, כמה ואיך
מאגר זה נועד להמחיש ולהסביר איך לקבל "הישגים" בגיטהאב ולמה זה בכלל טוב.

## אז מה זה אומר "הישג"?
פלטפורמת גיטהאב היא הרבה יותר מ"שרת אחסון קוד", היא מהווה "רשת חברתית למפתחים", לכן מפתחים פעילים מקבלים תגיות של "הישגים", המשווים לפרופיל יוקרתיות ומדרבנים משתמשים להיות פעילים יותר.

## למה זה טוב?
 - פרופיל מקצועי ומרשים יותר.
 - נראה טוב יותר כשירצו לקבל אותך לעבודה.
